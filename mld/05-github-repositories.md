# Relevant GitHub repositories

These repository URLs and the linked paths were checked on 2026-11-13.

1. [data-privacy-stack/presidio](https://github.com/data-privacy-stack/presidio) — the maintained Presidio source repository. Inspect [`presidio-analyzer`](https://github.com/data-privacy-stack/presidio/tree/main/presidio-analyzer) for recognition and [`presidio-anonymizer`](https://github.com/data-privacy-stack/presidio/tree/main/presidio-anonymizer) for operators. The [text quick start](https://github.com/data-privacy-stack/presidio/blob/main/docs/getting_started/getting_started_text.md) is the closest upstream example to this lab.
2. [data-privacy-stack/presidio-research](https://github.com/data-privacy-stack/presidio-research) — evaluation material for recognizers and PII detection. Inspect its evaluation approach when moving beyond a single synthetic sentence; a working example alone does not measure misses and false alarms.

Presidio originated at Microsoft and has moved to the Data Privacy Stack organization. Use the maintained repository above when following source code or releases.
