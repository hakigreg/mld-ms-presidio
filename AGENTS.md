# Minimum Lab Deployment project instructions

When creating or materially changing a Lab, use `MINIMUM_LAB_DEPLOYMENT.md` as the source of truth for its scope, learning exercise, required `mld/` documents, and completion criteria.

- Keep the Lab focused on one fundamental, runnable behavior of the chosen technology. Prefer the simplest implementation that demonstrates it with sound basics.
- Keep the root README, the required `mld/` documents, and explanatory code comments aligned with what the Lab actually does. Update the relevant documentation when behavior changes.
- Verify the behavior you claim works and distinguish observed results from steps you could not run.
- Write project instructions, documentation, learner-facing text, and explanatory comments in English.
